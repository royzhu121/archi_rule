# 🔥 FireCheck Pro — 租户二次消防审图工具

> 适用于耐火等级一级大型商业综合体租户二次装修的**消防快速审图 Web 工具**。  
> 基于规则引擎 + 智谱 GLM 大模型，覆盖六大消防专业模块，自动输出审查结论与规范依据。

---

## 📌 适用边界

本工具仅适用于公司下辖已建成投运的**大型商业综合体租户二次装修快速审查**场景，建筑为多层民用建筑，地上地下耐火等级均为一级，且既有消防设施已完整存在。目标覆盖约 80% 的常规租户场景，**不替代完整人工审图**。

### ✅ 自动审图前置条件

- 不改变防火分区主边界
- 不改变原防烟分区主边界
- 不涉及专项审批、性能化设计、专家论证
- 不涉及中庭、步行街、共享疏散、异形大空间等复杂场景
- 不涉及消防泵、主风管、报警主机、阀组级系统重构

### 🔴 直接转人工复核场景

- 明火餐饮、火锅、烧烤、燃气厨房
- 电影院、KTV、电竞馆、密室逃脱、剧本杀
- 儿童乐园、儿童培训等儿童活动场所
- 中庭边界、步行街两侧商铺、共享疏散场景
- 超高净空、仓储堆高敏感场景
- 跨越原防火分区或防烟分区的改造
- 需要重算疏散出口数量、总疏散宽度、人员密度的复杂业态
- 原设计分区被打断或重构的情形

## 📐 各模块输出口径

### 🏗️ 5.1 内装修防火

- 普通商业零售、无明火轻餐饮：顶棚 **A 级**，墙面/隔断/地面原则上 **B1 级**
- 疏散走道、安全出口相关界面从严控制
- 已设喷淋和火灾自动报警时，除顶棚外可按条文判断是否降低一级
- 参考规范：GB 50222-2017 相关条文

### 💧 5.2 自动喷水灭火系统

- 业态画像库驱动，危险等级自动带出
- **中危险级 I**：单喷头最大保护面积 12.5㎡，最大间距 3.6m
- **中危险级 II**：单喷头最大保护面积 11.5㎡，最大间距 3.4m
- 最小间距按 1.8m 提示
- 梁、风管、灯槽、宽大障碍物影响喷头布置时提示补喷
- 新增到顶隔墙或接近顶板时，提示原保护范围失效并需补喷
- 参考规范：GB 50084-2017 相关条文

### 🌬️ 5.3 防烟排烟

输出内容：
- 是否需要排烟口
- 排烟口数量
- 排烟口面积（保留两位小数）
- 计算步骤
- 参考规范条文

校核口径：
- 排烟口至最远点水平距离按 **30m** 提醒
- 补风量原则上不小于排烟量的 **50%**
- 新隔墙不得破坏原防烟分区主边界
- 原设计分区被打断或重构时，直接转人工复核
- 参考规范：GB 51251-2017 相关条文

### 🚨 5.4 火灾自动报警

依据 GB 50116-2013 输出：
- 探测器类型
- 探测器数量
- 应急广播数量
- 应急广播功率
- 明火租户特殊要求

提醒规则：
- 新增到顶隔墙或近顶隔墙时，提示增设探测器
- 最远点至手动报警按钮步行距离按 **30m** 提醒
- 新分隔房间应校核声光报警与广播覆盖

### 💡 5.5 消防应急照明和疏散指示

依据 GB 51309-2018 输出：
- 出口标志数量
- 标志规格尺寸
- 标志连续性

提醒规则：
- 出口门上方设置安全出口标志灯
- 转角、袋形走道、视线中断位置补设疏散指示
- 疏散指示间距按 **20m** 做一般校核提醒
- 新增墙体、隔断、封闭房间影响连续性时，在影响项块中联动提示

### 🧯 5.6 消火栓及灭火器

**Step 1：火灾类别确认**
- 校核原火灾类别是否仍适用
- 常规零售按 A 类，重电气设备场景考虑 E 类
- 参考规范：GB 50140 相关条文

**Step 2：保护距离快速校核**
- 中危险级默认按 **20m** 控制
- 超限时输出建议补设或移位，或转人工复核

**Step 3：设置条件校核**
- 明显可见、便于取用、不得堵塞疏散
- 最不利点至少有 1 具覆盖
- 每个计算单元不少于 2 具

**消火栓底线要求**
- 不得遮挡、包封、圈占消火栓箱
- 栓口开启、取用、操作空间应满足要求
- 新平面下任一点应满足消火栓可达性校核
- 参考规范：GB 50974-2014 相关条文

## 🚀 快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/royzhu121/archi_rule.git
cd archi_rule
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 配置 API Key

**方式 A**：修改 `config.py`

```python
ZHIPU_API_KEY = "your_actual_api_key"
```

**方式 B**：创建 `.env` 文件（推荐）

```env
ZHIPU_API_KEY=your_actual_api_key
ZHIPU_MODEL=glm-4-plus
```

> 未配置 API Key 时，规则引擎仍可正常运行，仅 GLM 综合意见部分显示提示。

### 4. 启动服务

```bash
python run.py
```

服务默认运行在 `http://localhost:8000`，浏览器访问即可使用。

## 🚫 禁止改动项

### 禁止自动放行复杂场景

- 原设计防火分区被打断或重构
- 原设计防烟分区主边界被打断或重构
- 中庭、步行街、共享疏散、异形大空间
- 专项审批、性能化设计、专家论证
- 高风险业态、儿童活动场所、复杂疏散重算场景

### 禁止越界自动化

- 不做完整探测器布点设计
- 不做灭火器数量精算
- 不对主干系统重构场景给出自动合规结论
- 不对复杂分区重构场景给出自动放行结论
