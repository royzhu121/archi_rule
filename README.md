# 🔥 FireCheck Pro — 租户二次消防审图工具

> 适用于耐火等级一级大型商业综合体租户二次装修的**消防快速审图 Web 工具**。  
> 基于规则引擎 + 智谱 GLM 大模型，覆盖六大消防专业模块，自动输出审查结论与规范依据。

---

## 📌 适用场景

本工具专为 **已建成投运的大型商业综合体（耐火等级一级，多层民用建筑）** 中的租户二次装修消防审查设计，满足以下前提条件时可进行自动审查：

- 不改变防火分区 / 防烟分区主边界
- 不涉及专项审批、性能化设计或专家论证
- 不涉及中庭、步行街、共享疏散等复杂场景
- 不涉及消防主干系统重构

> ⚠️ **本工具不替代完整人工审图**，目标覆盖约 80% 的常规租户场景。明火餐饮、电影院、KTV、儿童乐园等高风险业态将自动转为人工复核。

---

## ✨ 功能特性

| 模块 | 能力 |
|------|------|
| 🏗️ **内装修防火** | 顶棚 / 墙面 / 地面材料等级自动判定，依据 GB 50222-2017 |
| 💧 **自动喷水灭火系统** | 危险等级自动识别、单喷头保护面积 / 间距校核、补喷提示 |
| 🌬️ **防烟排烟** | 机械排烟量计算、排烟口数量 / 面积、服务距离校核 |
| 🚨 **火灾自动报警** | 探测器类型 / 数量、应急广播功率，依据 GB 50116-2013 |
| 💡 **消防应急照明和疏散指示** | 出口标志数量 / 规格、连续性校核，依据 GB 51309-2018 |
| 🧯 **消火栓及灭火器** | 火灾类别确认、保护距离校核、设置条件校核 |
| 🤖 **AI 综合意见** | 由智谱 GLM 大模型生成完整的综合审查意见 |

---

## 🛠️ 技术栈

- **后端**：Python 3.11+ / FastAPI / Uvicorn
- **前端**：原生 HTML + CSS + JavaScript（无框架依赖）
- **AI**：智谱 GLM-4-plus（[ZhipuAI](https://open.bigmodel.cn/)）
- **规范库**：内置 GB50016 / GB50084 / GB50116 / GB50222 / GB50974 / GB51251 / GB51309 条文数据库
