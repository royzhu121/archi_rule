## 简介

FireCheck Pro 专为公司下辖已建成投运的**大型商业综合体租户二次装修**消防快速审查场景而设计。输入租户业态与改造信息，系统自动输出六大消防专业的审查结论、整改建议与规范依据，并由智谱 GLM 生成综合审查意见。

> 本工具用于辅助快速审查，不代替完整人工审图。

## 功能模块

| # | 模块 | 核心能力 |
|---|------|---------|
| 1 | 🏗️ **内装修防火** | 顶棚 / 墙面 / 地面燃烧性能等级自动判定（GB 50222） |
| 2 | 💧 **自动喷水灭火** | 危险等级自动识别；喷头保护面积 / 间距校核；补喷提示 |
| 3 | 🌬️ **防烟排烟** | 机械排烟量计算；排烟口数量 / 面积；服务距离校核 |
| 4 | 🚨 **火灾自动报警** | 探测器类型 / 数量；应急广播功率；手报步行距离校核 |
| 5 | 💡 **应急照明 & 疏散指示** | 出口标志数量 / 规格；连续性校核；补设位置提示 |
| 6 | 🧯 **消火栓 & 灭火器** | 火灾类别确认；保护距离校核；设置条件核查 |
| ★ | 🤖 **AI 综合意见** | 智谱 GLM-4-plus 生成完整综合审查意见 |

## 适用边界

### ✅ 可自动审图的前提条件

- 不改变防火分区 / 防烟分区主边界
- 不涉及专项审批、性能化设计、专家论证
- 不涉及中庭、步行街、共享疏散、异形大空间等复杂场景
- 不涉及消防泵、主风管、报警主机、阀组级系统重构

### 🔴 以下场景直接转人工复核

| 类别 | 示例 |
|------|------|
| 高风险餐饮 | 明火餐饮、火锅、烧烤、燃气厨房 |
| 高风险娱乐 | 电影院、KTV、电竞馆、密室逃脱、剧本杀 |
| 儿童活动场所 | 儿童乐园、儿童培训、亲子类 |
| 复杂空间 | 中庭边界、步行街两侧商铺、共享疏散 |
| 分区重构 | 跨越原防火分区 / 防烟分区、原分区被打断或重构 |
| 复杂疏散 | 需重算出口数量、总疏散宽度、人员密度 |

## 快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/Tingtinggogogo/firecheck-pro-archi-rule.git
cd firecheck-pro-archi-rule
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 配置 API Key

方式 A — 修改 `config.py`：

```python
ZHIPU_API_KEY = "your_api_key_here"
```

方式 B — 创建 `.env`（推荐）：

```env
ZHIPU_API_KEY=your_api_key_here
ZHIPU_MODEL=glm-4-plus
```

> 未配置 API Key 时规则引擎仍正常运行，仅 AI 综合意见部分不可用。

### 4. 启动

```bash
python run.py
```

启动后优先访问：

- `http://localhost:8000`
- `http://127.0.0.1:8000`

若某些环境中 `localhost` 被代理或解析异常，请使用 `127.0.0.1`。
